# Coonnection

> 크래프톤 정글 5기 나만의 무기 프로젝트

관심사 기반으로 매칭된 사용자들이 마스크를 쓰고 비디오 채팅을 통해 대화할 수 있는 웹 서비스

## 프로젝트 정보

**기간** : 2024.06.20 ~ 2024.07.27 (5주)

## 팀 구성

| 팀원 | 역할 |
|:---|:---|
| **김세연 (팀장)** | 프로젝트 총괄, 미디어파이프 아바타 연동 |
| **김도연** | CRUD (RESTful API, Frontend), DB 관리 (MongoDB, Redis), 로그인 및 인증 (JWT, S3), UI (Tailwind CSS, 반응형), 상태관리 (Redux) |
| **최상욱** | 인프라, 오픈비두, 미션 알고리즘 |
| **주소미** | 매칭 알고리즘, 동작인식, 표정인식, 미션 알고리즘 |
| **심우정** | 음성인식 STT, TTS |

## 기술 스택

| 분류 | 기술 |
|:---|:---|
| Frontend | React, WebRTC, Tailwind CSS, Redux |
| Backend | Node.js, FastAPI, OpenVidu |
| Database | MongoDB, Redis, Amazon S3 |
| Infra | Amazon EC2, Docker |

## 주요 기능

1. 마스킹 기능
2. 관심사 기반 매칭
3. AI 주제 추천 및 피드백
4. 음성인식 및 STT, TTS
5. 실시간 제스쳐 인식 기반 퀴즈
